# A股大盘选股策略

策略源自 [tradingagents-astock](https://github.com/simonlin1212/tradingagents-astock)（v0.5.20，Apache-2.0）的分析框架，压缩为本仓库自包含的五阶段流水线。核心信念：**A股是政策市 + beta 市场——先判断环境，再选股；宁可不选，不可选错。**

## 何时使用

- 用户要求"选股"、"今天有什么值得买"、"跑一遍选股"、"A股分析"
- 需要给出具体买入价、止损价、卖出价时

## 快速运行

```bash
# 裸跑（默认 NIM 免费额度，模型 deepseek-v4.1-flash）
python main.py

# 指定数量 / 输出目录 / 调试
python main.py --max-picks 8 --output reports/ --debug

# 换 provider（见 .env.example 的方案 B/C/D）
python main.py -p deepseek
```

前置：`.env` 中配置 `NVIDIA_API_KEY`（build.nvidia.com 免费申请）或对应 provider 的 key。输出落在 `reports/YYYY-MM-DD_HHMMSS/`（report.md + picks.json + run_meta.json）。

## 五阶段流水线（app 自动执行）

| 阶段 | 做什么 | LLM calls | 输入源 |
|---|---|---|---|
| 1 大盘体检 | 判定 regime（进攻/防守/震荡）、温度、风格、回避板块 | 1 | 指数快照+趋势、涨跌家数、主力资金、北向、市场新闻/财联社 |
| 2 量化初筛 | 硬过滤（ST/次新/低价/低流动性/追高）+ 多因子打分（动量/量价/资金/热度/估值，权重随 regime 切换） | 0 | 全A清单（~5000支）、涨停榜 |
| 3 LLM 快筛 | 批量打分 0-100 + 一句话理由 | ~4 | 前 30 只候选（分批 8 只/批） |
| 4 深度分析 | 5 维度评价（基本面/技术面/资金面/消息面/风险）→ 值得买入/可关注/放弃 | ~15 | 前 15 只（每只1 call，含K线动量+题材归因+资金流） |
| 5 买卖定价 | 技术锚点（MA/BOLL/ATR/高低点）+ LLM 定价 + 校验 + 规则兜底 | ~10 | ≤10 只（每只1 call） |

## A股规则（贯穿所有阶段，不可省略）

1. **T+1**：今天买入明天才能卖出——追高 = 在当日峰值被锁仓
2. **涨跌停**：主板 ±10%、科创/创业 ±20%、北交所 ±30%；涨停不追、跌停不接飞刀
3. **估值框架**：PE 30-50x 是 A 股常态而非泡沫，但 >50x 需要业绩增速 ≥30% 支撑，否则进入 30x 消化框架
4. **政策市**：政策方向 > 业绩 > 技术形态；监管收紧期（如减持新规）回避政策受损板块
5. **量在价先**：缩量上涨不可持续，放量下跌是出货信号
6. **减持新规**：破发、破净、分红不达标的股票，控股股东禁止减持——这类"减持豁免"反而是安全垫
7. **散户占比 >60%**：情绪化定价显著，消息面与资金面背离时信资金面
8. **涨跌停板制度下的流动性陷阱**：涨停买不进、跌停卖不出，挂单价格必须留出缓冲

## 买卖定价规则（Stage 5）

- **锚点**：MA5/10/20/60、BOLL 上下轨、ATR14、20/60日高低点、现价
- **买入区间**：优先"回调至 MA10-MA20 + 放量企稳"；现价上方超过 ±15% 的挂单视为不现实
- **止损**：≤ 2×ATR14 或跌破关键支撑（MA20/前低）
- **目标**：10-25%（震荡市取下限，进攻市取上限）；卖出价分两档（第一目标位减仓、第二目标位清仓）
- **校验**：`stop < entry_low ≤ entry_high < target_low ≤ target_high`，不满足则规则兜底（MA20 回调 + 2×ATR 止损 + 10-25% 目标）
- **仓位**：单票 ≤25%，总仓位随 regime（进攻 60-80%、震荡 30-50%、防守 ≤30%）

## 数据源与降级链

| 数据 | 主源 | Fallback | 封禁表现 |
|---|---|---|---|
| 行情/估值 | 腾讯 qt.gtimg.cn (GBK) | 东财 push2 | RemoteDisconnected |
| K线 | 东财 push2his（前复权） | 新浪 CN_MarketData（可能滞后一天） | 同上 |
| 指数快照 | 东财 ulist（含涨跌家数） | 腾讯指数（**无涨跌家数**，标注缺失防误读） | 同上 |
| 全A清单 | 东财 clist 分页 | — | 同上 |
| 涨停热股 | 同花顺 getharden（题材归因） | — | 返回空 |
| 北向资金 | 同花顺 hsgtApi 分钟级 | 本地逐日 CSV 缓存（上游 2024-08 停发历史） | 返回空 |
| 新闻 | 东财 np-weblist | 财联社 cls.cn POST | 同上 |

所有东财调用经 `em_get()` 串行节流（1.0s + 0.1~0.5s 抖动）防封。任何数据缺失在报告中标注 `[数据缺失]`，不静默跳过——Stage 1 拿不到涨跌家数时会降级为"仅按指数涨跌判断"。

## 无 LLM key 时（降级模式）

app 在没有 key 时会报错退出。此时可以：
1. 手动跑 Stage 1+2（0 LLM calls）：`python -c "from astock.pipeline import ..."` 拿到量化初筛结果
2. 把初筛结果交给 Claude（本 skill 的宿主），由 Claude 按 Stage 3-5 的规则人工分析

## 输出格式

`reports/<时间戳>/` 下：
- **report.md**：大盘体检 → 筛选漏斗 → 最终选股表（代码/名称/评级/买入区间/止损/卖出区间/仓位/理由）→ 详情（5维评价+定价依据）→ 免责声明
- **picks.json**：结构化选股结果（供程序消费）
- **run_meta.json**：运行参数、LLM 调用次数、数据源可用性快照

## 风险提示

本工具输出仅为 AI 生成的分析参考，不构成投资建议。A股有风险，入市需谨慎。
